# geektime-dl

把极客时间装进 Kindle

## 安装

```bash
pip install git+https://github.com/jachinlin/geektime_dl.git
```

## 快速开始

```bash
# 1. 登录验证
geektime login -a <account> -p <password>

# 2. 查询课程列表
geektime query -a <account> -p <password>

# 3. 制作电子书
geektime ebook <course_id> -a <account> -p <password>
```
